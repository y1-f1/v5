## ✨ عن المشروع

Pix هو مشروع واجهة أمامية لمساعد ذكاء اصطناعي. تم تصميم الواجهة لتكون عربية من البداية، مع دعم اتجاه الكتابة من اليمين إلى اليسار وتجربة استخدام مناسبة للهاتف وسطح المكتب.

التصميم يستلهم بعض أنماط الاستخدام من ChatGPT وClaude وArena، لكنه يحتفظ بعلامة Pix وتوزيعه الخاص.

## 🧩 مكونات الواجهة

| الجزء | التفاصيل |
|---|---|
| الشريط الجانبي | محادثة جديدة، بحث، أقسام مساحة العمل، المحادثات الأخيرة، مدخل الحساب |
| الحساب والإعدادات | الوصول إلى الإعدادات من عنصر الحساب أسفل الشريط الجانبي |
| الإعدادات | صفحة كاملة الشاشة للمظهر وحجم النص وسلوك Enter |
| المحادثة | رسائل دون صور بروفايل أو شعارات بجانب الفقاعات |
| حقل الكتابة | كتابة متعددة الأسطر، إرفاق ملفات، قائمة أدوات، اختيار نموذج، إرسال |
| الأيقونات | SVG محلية داخل المشروع |
| المظهر | وضع فاتح وداكن، مع ألوان مستوحاة من Arena |

## 🎨 الهوية البصرية

- خلفيات دافئة بدل الأبيض/الأسود الحاد.
- لون ذهبي هادئ كلون إبراز.
- تباين واضح للنصوص والأسطح.
- شعار Pix الأصلي.
- لا توجد صور شخصية أو شعارات داخل فقاعات المحادثة.
- الواجهة RTL مع مراعاة أحجام الشاشات الصغيرة.

## 🗂️ بنية ملفات الواجهة

كل ملفات الواجهة الحالية داخل `local-ui/`:

| الملف | المسؤولية |
|---|---|
| `index.html` | الهيكل وعناصر الواجهة |
| `styles.css` | التصميم، الألوان، التجاوب، الحركات |
| `app.js` | التفاعلات وحالة الواجهة والتفضيلات |
| `icons.js` | مكتبة أيقونات SVG المحلية |

## 🚀 تشغيل الواجهة محليًا

لا تحتاج الواجهة الحالية إلى تثبيت حزم npm لتشغيلها؛ فهي ملفات ثابتة.

```bash
git clone https://github.com/y1-f1/v5.git
cd v5
git checkout preview/pix-chat-interface
cd local-ui
python -m http.server 8080
```

افتح في المتصفح:

```text
http://localhost:8080
```

## 🛠️ ملاحظات للمطور

1. ابدأ من فرع `preview/pix-chat-interface`.
2. ملفات الواجهة في `local-ui/`.
3. حافظ على هوية Pix والألوان الحالية واتجاه RTL.
4. لا تحذف أدوات حقل الكتابة دون طلب.
5. الإعدادات يجب أن تظل صفحة كاملة الشاشة.
6. لا تضف صور بروفايل أو شعارات بجانب فقاعات الرسائل.
7. اختبر على الهاتف بعد كل تعديل.
8. افحص Console وNetwork قبل النشر.
9. اربط AI والملفات والأدوات عبر Backend، ولا تضع الأسرار في الواجهة.
10. نظّف قواعد CSS المتكررة بحذر، مع الحفاظ على النتيجة المرئية.
